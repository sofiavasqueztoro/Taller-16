Instrucciones de ejecución:

1. Asegúrese de tener instalado Python con los paquetes numpy, astropy y matplotlib.
2. Coloque el archivo galaxy_cartesian_coordinates.ecsv en el mismo directorio que analisis_estructuras.py.
3. Ejecute en la terminal:
   python analisis_estructuras.py
4. El programa generará automáticamente los archivos:
   catalogo_clusters.ecsv, catalogo_voids.ecsv, trazado_filamentos.ecsv,
   estadisticas.txt, distribucion_galaxias.pdf, estructuras_clasificadas.pdf,
   clusters_y_voids.pdf y red_cosmica_completa.pdf.
